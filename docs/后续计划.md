该文档主要列出后续GitDocument的功能、机制等升级优化事项。

## 1，整体功能

- [ ] 基于PGroonga实现文章检索
- [ ] 支持文章下载导出为`md/pdf`，或文集打包下载
- [ ] 组织-用户模型，支持用户和文集按组织分组，使用组织隔离用户和文集
- [ ] AI智能体辅助接入

## 2，后端机制

- [ ] IP数据库按需下载或定期自动更新，而不是内嵌固定数据库和全量加载形式
- [ ] 文集/用户管理分页
- [ ] 文章阅读：
	- [ ] 相对路径文章引用支持
	- [ ] 文档内视频支持（相对路径/直链）

## 3，前端

- [ ] 文章阅读页面内切换文章菜单重写
